# THE LAST AGENT — AI 예측 배틀 백엔드

KBO 경기 결과를 예측하는 AI 성향을 선택하고, 스킬 카드 투표로 전략을 조립한 뒤 결과를 체인에 봉인·정산하는 서비스의 기획·분석·백엔드 포트폴리오 자료입니다.

## 담당 범위

- Spring Boot 기반 마켓 진행과 상태 전이
- 전략 슬롯 조립, canonical JSON·Keccak256 해시 생성
- 체인 어댑터 연동, 부분 공개 재시도, 점수·정산 결과 반영
- PostgreSQL 저장 구조와 결과 조회 경계 설계

## 핵심 트러블슈팅

1. JSONB 재직렬화와 JPA 쓰기 지연으로 전략 해시가 달라지던 문제
2. 일부 예측 공개 후 재시도하면 `409 ALREADY_REVEALED`가 발생하고 서버가 `LOCKED`에 남던 문제

## 문서

- `docs/`에 서비스 기획, KBO 파트 선택 분석, 블록체인 학습 노트를 정리했습니다.
- `diagrams/a303_architecture.png`에 투표·전략, 봉인·정산, 결과 공개 흐름을 시각화했습니다.
