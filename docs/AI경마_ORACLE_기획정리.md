# ORACLE — AI 경마 프로젝트 기획 정리 (회의 반영판)

> **한 줄 정의**: 서로 다른 "판단 설계(LangGraph)"를 가진 AI 3종이 같은 질문을 예측하고,
> 유저는 이번 질문을 가장 잘 맞힐 AI를 골라 코인을 스테이킹하는 게임.
> **AI(그래프 설계)가 메인, 블록체인은 정산·기록 계층(서브).** 사행성 배제.

---

## 1. 게임 루프 (한 판)

```
① 질문 공개 (5지선다 이상, 분야 태그)
② AI 3종이 각자 답 생성 (LangGraph 파이프라인)
③ 답의 해시를 온체인에 봉인 (커밋) ← 조작 불가 보증
④ 유저: "이번엔 어떤 AI가 맞힐까" 선택 + 코인 스테이킹 (placeBet)
⑤ 선택 마감 → AI 답 원문 공개 (리빌, 해시 대조)
⑥ 실제 결과 확인 → 적중 AI 확정 (근거 URL 공시 + 관리자 지갑 서명)
⑦ 적중 유저에게 시스템 풀에서 고정 배율 보상 지급
⑧ 코인으로 스킬 구매 → 다음 판 AI에 영향 (게임 루프 완성)
```

## 2. 확정된 설계 결정 (컨설팅 회의 반영)

| 결정 | 내용 | 이유 |
|---|---|---|
| AI가 메인 | 서비스 정체성 = 에이전트 경쟁 관람·분석 | 포폴 트렌디함, AI 특화 어필 |
| 단일 모델 + 클라우드 API | 자체 GPU 서빙 안 함 (경량 모델 셀프호스팅 배제) | 클라우드 의존 + LangGraph 조합도 뒤쳐진 느낌 아님 (컨설턴트 확인) |
| 차별화 = 그래프 설계 | 모델 3종 비교가 아니라 **LangGraph 파이프라인 3벌을 다르게 설계** | 모델 비교는 포폴 가치 낮음, 그래프 설계 능력이 어필 포인트 |
| 5지선다 이상 | O/X 금지 | 기저선 20% 이하여야 적중률·재현율 등 성능 지표가 유의미 |
| 사행성 배제 | 제로섬 재분배(패자 풀 분배) 없음 | 게임 요소로 대체, 규제·이미지 리스크 제거 |
| 작업량 3배 감수 | 파이프라인 3벌 설계 | 포폴·앱 성격상 제일 유리한 방향 (팀 합의) |

## 3. AI 파이프라인 (작업량 3배를 1.3배로)

**그래프 3벌을 통째로 만들지 않는다.** 공통 골격 1벌 + 전략 노드만 교체:

```
[질문 분류] → [컨텍스트 수집 ◀ AI별로 다름] → [답 생성] → [형식 검증/JSON]
```

- AI 1종 = 전략 객체 = { 페르소나 프롬프트 + 컨텍스트 수집 함수 + temperature }
- **SAGE**(안정형): 과거 통계·평년값 조회 주입
- **MOMENTUM**(추세형): 최근 N일 데이터 주입
- **REVERSE**(반전형): SAGE·MOMENTUM의 답을 입력받아 반대 근거 탐색
  → 병렬 2 + 합류 1의 실행 의존성 = LangGraph 분기·병렬·합류가 필수인 진짜 이유
- 판정 노드: 결과 대조 → 적중 AI 결정 → 전적(전체/분야별/최근) 갱신
- 성능 지표: AI별 적중률, 분야별 강약 매트릭스, (심화) 확신도 반영 스코어
- 모니터링·리포트 화면 = AI 특화 포폴 재료

## 4. 블록체인 계층 (명세 필수 흐름에 그대로 매핑)

| 명세 요구 | 우리 서비스에서 |
|---|---|
| 선택지 (2개 이상) | AI 3종 (SAGE/MOMENTUM/REVERSE) |
| placeBet (토큰 스테이킹) | 유저가 고른 AI에 코인 걸기 — **필수 흐름 유지** |
| resolve (정답 확정) | 적중 AI 확정, 관리자 지갑 직접 서명 + 근거 공시 |
| 정산·보상 전송 | **시스템(스폰서) 풀에서 고정 배율 지급** — sponsorReward 필드 활용, 제로섬 아님 |
| 환불 모드 (선택과제) | AI 동률 적중 시 전원 환불 |
| (명세 밖 차별화) | **커밋-리빌**: AI 답 해시 선봉인 → 마감 후 공개·대조 |

⚠ **주의: "블록체인은 포장지"여도 점수는 여기서 나온다.**
평가 배점의 절반 이상이 참여 컨트랙트·영수증 검증·온체인-DB 정합성·복구.
사행성 배제 ≠ 스테이킹 제거 — 코인을 걸지 않으면 placeBet 필수 요구 미충족.

"왜 블록체인?"에 대한 답: ① AI 답 봉인(숨기되 조작 불가) ② 스테이킹 에스크로(운영자도 못 만짐)
③ 공식대로 자동 정산 ④ AI 전적 위변조 불가(선택의 근거인 성적표를 아무도 못 고침)

## 5. 게임 요소 (사행성의 자리를 채우는 것)

- **스킬트리**: 획득 코인으로 스킬 구매 → AI 그래프에 컨텍스트로 주입되어 예측에 영향
  - 설계 가드레일: 스킬 슬롯 수 제한 + 스킬당 토큰 예산 상한 (컨텍스트 폭발·비용 폭증 방지)
  - 전적 순수성: 스킬 적용 전적과 기본 전적 분리 집계 (또는 스킬은 팀전 모드 한정)
- 팀전(주 단위 경쟁), 시즌제 리더보드, 아바타는 제외 (회의 결정)
- 비용 구조: 유저 수와 LLM 토큰 비용 무관(호출은 판당 고정) — 단 스킬 주입 시 호출당 토큰 증가

## 6. 역할 분배 (6인, 주력+겸업)

| 사람 | 주력 | 겸업 |
|---|---|---|
| **준성** | 체인 연동 백엔드: 영수증 검증·멱등·복구·정산, 커밋-리빌 오케스트레이션 | E2E 통합 오너 (부분 실패 5종, 대조표) |
| B | 이벤트·전적·보상 API, DB, 판 자동 생성 배치 | 전략① SAGE |
| C | 컨트랙트 (팩토리·참여·확정·정산 + 커밋 해시 확장) + 테스트 | 전략② MOMENTUM (후반) |
| D | LangGraph 골격 (분류·병렬·REVERSE 합류·판정·전적) | 전략③ REVERSE, 밸런스 튜닝 |
| E | 유저 화면 (질문·AI 카드·스테이킹 상태머신·지갑) | 페르소나 프롬프트 |
| F | 관리자 화면 (확정·정산·근거 공시·tx 검증 UI), 전적 시각화 | 발표 자료 |

**주차 흐름**: 1주 계약 문서 3종(API·컨트랙트 시그니처·전략 인터페이스) →
2~3주 필수 흐름 관통(AI는 더미 전략) → 4주 겸업 스프린트(전략 3종·스킬) → 5주 E2E·밸런스·발표.
겸업은 전부 "배점 없는 AI 방향"으로만 — 일정이 밀려도 점수(필수 흐름)는 안 다치는 배치.

## 8. 리스크와 방어

| 리스크 | 방어 |
|---|---|
| "블록체인 구색 맞추기" 공격 | 커밋-리빌·전적 위변조 불가 = 블록체인 없으면 성립 안 하는 지점 2개 확보 |
| 한 AI 독주 → 게임 수렴 | 분야별 강약을 전략 설계로 통제, 밸런스 튜닝 스프린트 확보 |
| 스킬트리 비용·공정성 | 슬롯·토큰 상한, 전적 분리 집계 |
| AI에 인력 쏠려 필수 흐름 부실 | 겸업 방향 고정(주력=배점, 겸업=AI), 더미 전략으로 흐름 먼저 관통 |
| AI 동률 적중 | 환불 모드 (명세 선택과제 겸용) |
